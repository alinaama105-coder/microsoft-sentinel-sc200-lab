# Microsoft Entra ID Sign-in Investigation Lab

## Environment

I created a Microsoft Entra ID practice environment and used a dedicated test account for identity-security exercises.

The lab included:

- Test tenant
- Test user
- Security group
- Sign-in activity
- Conditional Access exercises

## Sign-in Log Exercises

I generated and reviewed both successful and failed authentication events.

One failed sign-in produced error code:

`50126`

This provided an opportunity to practise reading Entra ID sign-in logs and understanding the authentication result in context.

## Investigation Process

1. Open Entra ID sign-in logs.
2. Locate the relevant user/event.
3. Review date/time and status.
4. Review the authentication result/error.
5. Examine available sign-in context.
6. Compare successful and failed events.
7. Document the outcome.
