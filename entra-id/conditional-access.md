# Conditional Access Exercise

## Objective

Develop familiarity with Microsoft Entra Conditional Access as an identity-security control.

## Lab Work

A test security group was used as part of the Entra ID practice environment.

The exercise focused on understanding the relationship between:

- Users and groups
- Sign-in activity
- Access decisions
- Conditional Access policies
- Identity-focused investigation

## SOC Relevance

Conditional Access provides important context when investigating identity-related alerts. A SOC analyst may need to understand which access controls applied to a user, whether authentication succeeded and what policy-related information is available in the sign-in record.

This repository documents training exercises only and does not contain production tenant configuration.
